# HW02 submission source

This directory contains editable materials used to produce the final submission package.

- `report/latex/`: modular LaTeX report template.
- `features/A`–`features/D`: per-feature spec, domain, BVA, cases, review, execution, and gap records.
- `bugs/`: Markdown bug report and GitHub issue index.
- `evidence/A`–`evidence/D`: real execution screenshots and related evidence.
- `ai/`: AI audit, critique, disclosure, prompt log, and raw transcripts.
- `skills/`: reusable agent skills developed for the assignment.
- `demo/`: demo links and recording notes.
- `supporting/`: scope, environment, process log, summary, checklist, and defense notes.
- `scripts/`: scripts actually used during testing.

Do not place secrets, tokens, `.env` files, fabricated evidence, or the complete SUT clone in the final ZIP.
